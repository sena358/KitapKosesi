# 📚 KitapKöşesi – Online Bookstore Website

KitapKöşesi is a responsive online bookstore website developed to practice front-end web development and create a clean, user-friendly shopping interface.

## 🚀 Features

- Responsive design for different screen sizes
- Book catalog and individual product pages
- Shopping cart interface
- Login page
- About Us and Contact pages
- Organized and reusable CSS components
- Easy navigation between pages

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts and responsive design
- **Visual Studio Code** – Development environment
- **Git & GitHub** – Version control and project hosting

## 📁 Project Structure

```text
KitapKosesi/
├── index.html
├── pages/
│   ├── catalog.html
│   ├── product.html
│   ├── cart.html
│   ├── login.html
│   ├── about.html
│   └── contact.html
├── css/
│   ├── base.css
│   ├── layout.css
│   ├── components.css
│   └── pages.css
└── README.md
```

## 💻 Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.

This project was created to improve my front-end development skills, focusing on responsive web design, reusable CSS structures, page organization and user experience.

# 📚 KitapKöşesi – Online Kitap Mağazası

- Telefon, tablet ve bilgisayarlara uyumlu tasarım
